    - `下方左右名單盒` 依 `上表中線` 動態計算左右寬度
    - 再把計算結果轉成 `flex` 比例，寫回白盒分配
  - 這輪明確確認幾件事：
    - 不能只改上表欄位比例
    - 也不能只用固定比例，例如 `1.04 / 0.96`
    - 因為每個職業、每個組別的名字長度與數值擁擠程度不同
    - 固定比例只能局部有效，無法全頁通用
  - 中間嘗試過但最後沒有採用的方向：
    - 直接用 `px` 強塞下方白盒寬度
    - 直接把上表總寬硬縮到下方白盒群
    - 單純加固定 `px bias`
  - 最後定案的思路是：
    - 先取 `上表` 第 `3 / 4` 欄中間分隔線位置
    - 以該位置換算出下方左右白盒的理論左右寬
    - 必要時先乘一個 `左側補正倍率`
    - 再把左右寬換成 `flex ratio`
    - 用 `flex` 去控制下方兩盒分配，因為這一層是實測真正會生效的層
  - 這輪也記下一個明確教訓：
    - 如果某種寫法極端放大後，畫面幾乎沒變，就代表沒有控制到真正生效的版面層
    - 這次 `寫死 flex 比例` 會生效，但 `直接塞 px 寬度` 幾乎不動，表示兩者不是在調同一層
    - 類似問題不要太快沉進局部技術細節
    - 要先做「極端值測試」確認哪個參數真的會讓畫面大幅變化
    - 如果極端值都幾乎沒反應，就應立刻懷疑是改錯層，而不是繼續微調公式
    - 下次遇到版面問題，優先順序應改成：
      - 先找真正生效的控制點
      - 再決定要不要做更精細的幾何計算或補正
  - 目前實作口徑：
    - 先算理論左寬 / 右寬
    - 再乘 `左側補正倍率`
    - 右側用剩餘空間補足
    - 最後轉成 `flex` 比例套回左右白盒

#### 特質系統

特質是寵物的核心能力詞條，性質分兩種：
- **大多數特質**：被動生效，持有即有效果（莊園、採集、探索等）
- **戰鬥類特質**：類似主動技能，需手動拖入**角色技能欄**才在戰鬥中生效

每隻寵物最多攜帶 **4 個特質**：1 個戰鬥類（主動）+ 最多 3 個被動（同類型只能帶 1 個）

| 特質類型 | 說明 |
|----------|------|
| 戰鬥類 | 輔助玩家戰鬥，需佔用角色技能欄 |
| 莊園類 | 自動種植、灌溉、收穫、畜牧 |
| 探索類 | 自動解謎、偵測寶箱、提供照明 |
| 採集類 | 自動挖礦、採草藥、釣魚 |
| 閒趣類 | 演奏、騎乘、趣味動作等 |

- 特質品質分四級：初 → 優 → 精 → 絕

- 特質品質精品與絕品「性能差異較小」，絕品主要是數值微幅提升
